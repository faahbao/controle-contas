CONTROLE DE CONTAS

INICIAR BACKEND

cd D:\Projetos\controle-contas\backend
npm run dev

Backend:
http://localhost:3000

INICIAR FRONTEND

Abra outro terminal:

cd D:\Projetos\controle-contas\frontend
npm run dev

Frontend:
Use a URL exibida pelo Vite.
Normalmente:
http://localhost:3001

CONFIGURACAO DO BACKEND

Arquivo:
D:\Projetos\controle-contas\backend\.env

Conteudo minimo:

DATABASE_URL="file:./dev.db?connection_limit=1"
JWT_SECRET="substitua-por-uma-chave-forte-com-32-caracteres-ou-mais"
PORT=3000
FRONTEND_URL="http://localhost:3001"

COMANDOS PRISMA

cd D:\Projetos\controle-contas\backend

npx prisma generate
npx prisma migrate dev
npx prisma studio

PAGAR PARCELAS FUTURAS

1. Faca login.
2. Na secao Transacoes, clique em Ver todas as parcelas.
3. Selecione despesas pendentes.
4. Clique em Pagar selecionadas.

IMPORTANTE

- Receitas nao precisam ser pagas.
- O pagamento em lote ocorre uma parcela por vez.
- Nao use Promise.all para atualizar varias parcelas no SQLite.
- Se o navegador mantiver codigo antigo, use Ctrl + F5.
