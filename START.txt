FUNCIONALIDADES IMPLEMENTADAS

Receitas
  - Tipos: Salario, Freelance, Investimentos, Outros
  - CRUD completo
  - Filtros por categoria

Despesas
  - 10 categorias pre-configuradas
  - CRUD completo
  - Filtros por categoria
  - Marcacao de pago/pendente

Recorrencias
  - Marcacao de transacoes recorrentes
  - Periodo: Diaria, Semanal, Mensal
  - Geracao automatica de parcelas
  - Visualizacao de parcelas futuras

Pagamento
  - Pagamento individual de despesas
  - Pagamento em lote (multiplas despesas)
  - Pagamento antecipado de parcelas futuras
  - Desmarcar pagamento

Dashboard
  - Saldo total (Receitas - Despesas)
  - Totais por tipo
  - Grafico de receitas vs despesas
  - Filtros por mes/ano

Filtros
  - Por tipo (receita/despesa)
  - Por categoria
  - Por periodo (data)
  - Por recorrencia
  - Por status de pagamento

Relatorios
  - Geracao de PDF com resumo do mes
  - Inclui: receitas, despesas, saldo e transacoes
  - Filtro por mes/ano

Exportacao
  - Formato CSV
  - Compativel com Excel/Sheets
  - Com filtros aplicaveis

Interface
  - Menu lateral
  - Design responsivo
  - Suporte desktop e mobile
  - Cores intuitivas
  - Badges para recorrencias
  - Indicadores de pagamento

COMO COMECAR

1. Pre-requisito
   - Instale Node.js: https://nodejs.org/ (LTS)

2. Instalacao
   Windows:
     cd D:\Projetos\controle-contas\backend
     npm install
     npx prisma generate
     npx prisma migrate dev

     cd ..\frontend
     npm install

3. Iniciar Backend (Terminal 1)
     cd backend
     npm run dev

4. Iniciar Frontend (Terminal 2)
     cd frontend
     npm run dev

5. Acessar no navegador
   - http://localhost:3001 (ou URL exibida pelo Vite)

6. Comecar a usar!
   - Cadastre-se
   - Faca login
   - Adicione receitas e despesas
   - Veja o dashboard atualizar
   - Explore todas as funcionalidades

============================================================
PROBLEMAS COMUNS

Porta 3000 ocupada:
  Altere a porta no backend/.env:
  PORT=3001

  E atualize o frontend/.env:
  VITE_API_URL=http://localhost:3001/api

Erro no Prisma:
  cd backend
  npx prisma generate
  npx prisma migrate dev

Erro de login 404:
  - Confirme backend rodando na porta 3000
  - Confirme frontend usando URL correta da API
  - Confirme rota POST /api/auth/login no server.js
